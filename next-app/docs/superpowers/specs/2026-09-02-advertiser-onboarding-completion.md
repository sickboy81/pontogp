# Advertiser Onboarding Completion Spec

## Objective

Reduce advertiser draft abandonment while preserving explicit publication and server-side publication validation.

## Requirements

- The minimum publishable profile bio is 150 meaningful characters.
- Publication requirements are visible before the first draft is saved.
- The tab for the link-page feature is named "Link na bio" and cannot be confused with the profile description.
- Saving a draft continues to the first unresolved publication requirement.
- The advertiser dashboard links directly to the first unresolved requirement.
- The publication area explains every blocker and offers a direct action for each one, including on mobile.
- Completion percentage contains only actual publication requirements; prices are presented as optional/recommended.
- The description field provides practical writing prompts without generating filler.
- Onboarding step views, completions and errors are recorded as structured server logs without profile text, contact data, email, IP or user agent.
- Public profile visibility remains restricted to active profiles.
